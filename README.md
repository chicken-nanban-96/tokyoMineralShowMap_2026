# 12版：会場全体が分かるマップに修正

11版ではブースだけの模式図になり、会場外枠・出入口・通路・未登録ブースが消えていました。12版は公式フロアマップの全体像を表示し、検索・お気に入り・訪問順などの操作用SVGを**同一座標系**で重ねます。従来のような別CSSレイヤーの倍率ずれを防ぐための修正です。

- 公式図の外形・通路・入口・未登録ブースもすべて表示。
- ブースタップ、検索で緑、★お気に入りでオレンジ、訪問順の数字、個人データは維持。
- `この店舗の位置を表示` は位置未登録なら押せないまま。
- 公式図取得に失敗した場合は簡易図に自動切替。
- 地図下の不要な説明を普段は非表示に。
- 更新用の画像取得Actionは不要。店舗一覧の更新用のみ。

**注意：手元の `shops.json` は以前の191店版です。GitHub上の自動更新済み `shops.json` を絶対に上書きしないでください。**

## GitHubに更新するファイル

- `index.html`
- `app.js`
- `styles.css`
- `map.json` は11版と同じです。変更不要。
- `.github/workflows/update-shops.yml` も11版と同じ、店舗情報の更新専用です。変更不要。
- `shops.json` は上書きしないでください。

ZIP内では先頭に `.` を付けず `github_workflows/update-shops.yml` としています。GitHubに置く場合は `.github/workflows/update-shops.yml` の階層に配置してください。

## 既知の制限

ブースごとの枠の正確なサイズは全件確認済みではありません。現在の `map.json` に登録された座標を使って色付けしています。2階13〜97番など、地図上ではブースが見えていても、位置登録がなく検索による色付けや位置ジャンプに対応していない区画があります。この制限と、公式画像への依存は残っています。

公開URLで新しいJS/CSSが読み込まれない場合は、Safariで再読み込みしてください。ホーム画面版とSafari版で個人記録の保存領域が異なる場合があります。
