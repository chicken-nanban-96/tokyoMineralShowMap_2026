# 池袋ショーマップ 14版（浅草版と同じSVG描画）

## 13版からの重要な修正

- **13版のindex.htmlが`app.js?v=12`と`styles.css?v=12`のままだった問題を修正**。14版では `?v=14` としてiPhone Safariのキャッシュを更新します。
- 公式JPEGを背景に使用しないSVG描画です。ブースの四角がそのまま検索時の緑色・お気に入りのオレンジ色に変わります。
- 表示確認用に「開催情報・補足・公式リンク」の中に「表示エンジン：14版（SVG）」を追加。
- 3階層で互いに重なっていたブース枠は調整し、四角の重なりを除去。2FのB1〜B5、DB1、A15/B15、254〜263番周辺の明らかな座標衝突も調整。
- ブース座標自体は既存の概算データです。**公式図との全区画個別精密照合は未完了**。
- 2階の13〜97番は店舗とブースの位置対応が未登録で、そのお店の「位置を表示」は非活性。
- 記録データ・店舗の自動更新方式は変更なし。GitHub Actionsの実行は不要。

## GitHubへの反映

- `index.html`、`app.js`、`styles.css`、`map.json` はリポジトリ直下へ。
- `scripts/update_shops.py` は `scripts/update_shops.py` へ。
- `github_workflows/update-shops.yml` はGitHub上で `.github/workflows/update-shops.yml` へ。iPhoneで`.`で始まるフォルダが隠れる問題を避けるため、ZIP内では`github_workflows`という名前で梱包しています。
- **重要: 同梱の `shops.json` は191店舗の旧スナップショット。公開リポジトリの507店舗の `shops.json` は絶対に上書きしないでください。** 全ファイル入りという希望に合わせて旧データも参考用に同梱しています。

## iPhoneで古い地図が見える場合

Safariで公開URLを再読み込み。さらにSafariのアドレス欄で末尾に `?refresh=14` を付けて開くと、HTML自体の再取得も促せます。「開催情報・補足・公式リンク」に「表示エンジン：14版（SVG）」が出れば新しいHTMLです。
