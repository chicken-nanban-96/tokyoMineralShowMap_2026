# 11 池袋ショーマイマップ（浅草石フリマ版と同じ操作）

## 11版の変更

- 位置情報が登録されていない店舗の「この店舗の位置を表示」ボタンを非活性（押せない状態）に変更。押してからエラー表示する動作を廃止。
- ボタンの有効／無効は、店舗のブース番号と map.json の座標・幅・高さが対応しているかで判定。複数ブースのうち一つでも位置登録済みなら有効。
- 「訪問前／訪問済み」の表示は**浅草石フリマ版と同じ「□ 訪問前」「✓ 訪問済み」**を維持（ユーザーの指定）。
- 店舗詳細の毎回同じ説明文、重複していた収録数表示、古い「位置情報未登録と表示するよ」という説明を整理。
- 位置を表示できたことを知らせる通知や説明文は追加しない。ブースが緑色になる動作は10版のまま。
- お気に入り、訪問順、メモ、訪問済み、バックアップ、保存キー、位置データは変更しない。

## ZIP内のファイル構成

```
index.html
app.js
styles.css
map.json
shops.json
scripts/update_shops.py
github_workflows/update-shops.yml
README.md
```

**GitHub上の店舗データを守るための重要注意**：ZIPの `shops.json` は作業環境に残る**191店舗の旧データ**であり、既に自動更新された507店舗のデータではありません。**GitHubへアップロードするときは `shops.json` だけ上書きしないでください。** それ以外のファイルは今回のZIPからまとめて配置できます。

## GitHubへの配置

- `index.html`、`app.js`、`styles.css`、`map.json` はリポジトリ直下。
- `scripts/update_shops.py` は `scripts/` 以下。
- `github_workflows/update-shops.yml` は、GitHubでは **`.github/workflows/update-shops.yml`** に配置。解凍時に見えないドット始まりのフォルダを避けるため、ZIPでは `github_workflows` としています。
- `README.md` は説明用で、アプリ動作には必須ではありません。
- `shops.json` は今の GitHub 上の自動更新済みファイルを維持してください。

## 位置データについて

地図は浅草版と同じ SVG のブース直描画です。ただし `map.json` の位置・形状を公式図と全件照合したわけではありません。2階13〜97番など、位置未登録の店舗では位置表示ボタンを非活性にします。公式配置図へのリンクは補足情報に残しています。
